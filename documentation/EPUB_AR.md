# نسخة EPUB — من الكتب المقلوبة إلى قارئ إلكتروني

> آخر تحديث: 2026-10-21 · الفرع `arena/8c16ed4e-project`

---

## 1. ماذا أُضيف

كل كتاب ومقرر في الأكاديمية (18 مستنداً / 157 صفحة) يُبنى الآن بصيغتين
من **نفس المصدر**:

| الصيغة | الملف | القارئ |
| --- | --- | --- |
| EDB | `public/edb/*.edb` | القارئ ثلاثي الأبعاد داخل الموقع |
| **EPUB 3** | `public/epub/*.epub` | Kindle · Kobo · Apple Books · Calibre · أي برنامج قراءة |

الكتب منفصلة: ملف `book-vt.epub` مستقل يعمل بلا إنترنت وبلا خادم.

```bash
npm run epub:build   # يبني public/epub/ (18 ملفاً + فهرس + صفحة تحميل)
npm run epub:check   # يفشل إذا كانت الملفات الملتزمة قديمة
npm run site:check   # يتحقق من النسخ المنشورة في docs/epub
```

## 2. القرارات التصميمية (ولماذا)

**ثنائي اللغة في ملف واحد.** كل صفحة تعرض العربية أولاً ثم الإنجليزية
تحت بعضهما، لكل نص `lang` و`dir` الصحيحان. الترجمة إلى "طبعتين منفصلتين"
كانت ستضاعف الكتالوج وتكسر الروابط بين العربية والإنجليزية.
الملف يحمل `<dc:language>ar` و`<dc:language>en` معاً.

**الغلاف SVG مولّد، لا صورة ثابتة.** يُرسم من بيانات الكتاب (العنوان،
التخصص، الكود، الطبعة) فيأخذ لون كل تخصص، ويبقى حاداً على شاشة e-ink.
مقاس 1600×2400 (نسبة 2:3) كما تتوقع المتاجر.

**لا JavaScript ولا خطوط مضمّنة ولا موارد بعيدة.** الكتب لا تُنفّذ برامج،
و`validateEpub` يرفض أي `<script>` أو `src="http…"` داخل الملف.

**التجارب التفاعلية لا تُقلَّد.** لا يمكن تشغيل محاكاة داخل EPUB، لذلك
تتحول إلى ملاحظة صريحة بالعربية والإنجليزية + رابط نسخة الويب + معرّف
التجربة. لم أضع صورة ثابتة تدّعي أنها التجربة.

**التاريخ ثابت.** `dcterms:modified` يأتي من `EPUB_RELEASE_DATE`
(افتراضياً `2026-10-21T00:00:00Z`) لا من `new Date()`. بدون ذلك يتغيّر
الملف عند كل بناء ولا معنى لـ `epub:check` في CI.

**ZIP مكتوب بأيدينا.** `src/epub/zip.ts` نحو 180 سطراً: `mimetype` أولاً
وبدون ضغط كما يفرض المعيار، توقيتات ثابتة، ترتيب مدخلات ثابت، وCRC32
مُتحقَّق عند القراءة. أضفنا `fast-xml-parser` للتحقق من XML فقط.

## 3. ما يتحقق منه `validateEpub`

ليست بديلاً عن `epubcheck` (يحتاج Java وشبكة)، لكنها تفحص ما يكسر القارئات فعلاً:

- `mimetype` أول مدخل، `method 0`، محتواه بالضبط `application/epub+zip`؛
- `META-INF/container.xml` يشير إلى ملف حزمة موجود؛
- `unique-identifier` يطابق `dc:identifier`، والمعرّف UUID v5 مشتق من
  معرّف الكتاب وإصداره (ثابت بين عمليات البناء)؛
- `dc:language` بصيغة BCP-47، و`dcterms:modified` بصيغة `CCYY-MM-DDThh:mm:ssZ`؛
- كل عنصر في `manifest` وكل `itemref` في `spine` موجود فعلاً، ولا تكرار للمعرّفات؛
- مستند التنقل موجود وفيه `<nav epub:type="toc">`؛
- كل ملف XHTML سليم كـ XML وله `<title>`، وكل رابط داخلي يشير إلى ملف موجود؛
- لا موارد بعيدة في الـ manifest ولا محتوى برمجي؛
- تحذير لأي ملف غير مذكور في الـ manifest.

## 4. فحص مستقل بقارئ حقيقي

لم أكتفِ بفاحصي؛ جرّبت الملفات على مكتبة EPUB مستقلة (`@smoores/epub` في
بيئة منفصلة، غير مضافة إلى المشروع):

```
18/18 books opened, TOC'd and bilingual via @smoores/epub
```

كل كتاب فُتح، وقُرئ فهرسه، وتأكد وجود نص عربي وإنجليزي في الصفحات.
`epubjs` لم يُستخدم لأنه معلّق في Node (يحتاج DOM).

## 5. عيبان حقيقيان كشفهما الفحص

### 5.1 معادلات غير مقروءة

كانت الصيغة تُخرج:

```
E = (I)/(d^2) cos θ quad [text{Lux}], quad 1text{ fc} = 10.76text{ Lux}
```

`formatFormula` لم تكن تعرف `\text{}` ولا `\quad`. أُصلح في
`src/edb/format.ts` (مشترك بين القارئ والـ EPUB) والناتج الآن:

```
E = (I)/(d^2) cos θ [Lux], 1 fc = 10.76 Lux
```

### 5.2 نص عربي داخل عنصر `lang="en"`

في المصدر 209 وحدة نصية موجودة بلغة واحدة فقط: نصف ترجمة ناقص فعلاً
(أكثرها في RT 47، VT 42، Intro 35). الكود القديم كان يعرض العربية داخل
`<p lang="en" dir="ltr">`، أي يزعم أن النص إنجليزي.

القرار: **لا نُكرّر لغة مكان أخرى ولا نخترع ترجمة.**

- في EPUB: النص الناقص يُحذف من قائمة تلك اللغة فقط، ويبقى في لغته.
  (الحذف من القائمة يزحزح الترقيم، لذلك حُذف بدل ترك سطر فارغ.)
- العدد يُعلن: `epub:build` يطبع `translation gap: 209`، والفهرس
  الثابت يعرض لكل كتاب عدد مقاطعه أحادية اللغة، و`index.json` يحمل
  الحقل `untranslated` لكل كتاب.
- اختبار يمنع رجوع العيب: لا حرف عربي داخل أي عنصر `lang="en"`.

إكمال هذه الترجمات مهمة محتوى لاحقة، لا مهمة تنسيق.

## 6. الواجهة

- زر **EPUB** بجانب زر تنزيل `.EDB` داخل القارئ.
- أيقونة تنزيل EPUB على كل بطاقة في المكتبة (كتب ومقررات).
- رابط «نسخة EPUB للقراء الإلكترونيين» في رأس المكتبة يفتح
  `epub/index.html`: صفحة تحميل ثابتة تعمل حتى لو تعطّل التطبيق نفسه.

## 8. ما لم يُفعل

- **لا epubcheck رسمي** — يحتاج Java. الفحص الذاتي يغطي قواعد EPUB 3
  الأساسية، والملفات قُرئت بمكتبة مستقلة.
- **لا صور داخل الكتب** — المصدر لا يحتوي صوراً (`image` blocks = 0)،
  وأي صورة مستقبلاً تُدرج كما هي بحجمها الأصلي دون ضغط.
- **لا PDF** — يمكن توليده من EPUB لاحقاً إن احتيج.
- **الترجمات الناقصة** (209) لم تُملأ؛ أُعلنت فقط.
