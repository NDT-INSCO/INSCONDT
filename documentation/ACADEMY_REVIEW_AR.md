# مراجعة الأكاديمية وخطة استكمالها

تاريخ المراجعة والبحث: 16 أكتوبر 2026.

## نطاق المراجعة

تمت مراجعة مصدر القسم الذي يخدم `#academy`، وبنية المناهج والاختبارات والمعامل وتتبع التقدم وطريقة النشر. لا يُدّعى إجراء تدقيق اعتماد أو مراجعة جميع بنود الأكواد أو مقارنة بصرية مباشرة مع النسخة المنشورة. التغييرات في فرع العمل ولا تعني تحديث موقع GitHub Pages قبل الدمج والنشر.

## الموجود قبل التعديل

- ثمانية مجالات: الفحص التقليدي، المتقدم، اللحام، المعالجة الحرارية والمعادن، API، الدهانات والتآكل، الجودة، وسلامة الأصول والوصول بالحبال.
- مستويات ومسؤوليات ومتطلبات وعناوين وحدات ونتائج تعلّم ومراجع كتب.
- محاكاة ومعامل وبنك أسئلة وتتبع محلي للتقدم.
- مستشار ذكاء اصطناعي وتوليد فيديو يعتمدان على خدمات خادم لا يوفرها GitHub Pages وحده.

## أهم الفجوات

1. قوائم الموضوعات ليست دروساً؛ يحتاج المتعلم شرحاً متدرجاً وتمارين وتصحيحاً ومواد مرجعية واضحة.
2. عرض الساعات والشهادات بجوار المنهج قد يُفهم خطأً كاعتماد أو أهلية رسمية. لا ينبغي استخدام الأرقام العامة لإصدار حكم على التأهيل.
3. المحاكاة قد تعطي ثقة زائدة في مهارة ميدانية دون تدريب عملي. حساب PWHT أو العمر المتبقي ليس قرار تشغيل.
4. دليل الأكواد لا يحدد وحده إصدار العقد أو بند القبول؛ «أحدث إصدار» ليس بالضرورة الإصدار المطلوب.
5. بيانات التقدم محلية وليست سجلاً موثقاً للخبرة أو ساعات التدريب.
6. روابط المصادر تحتاج مراجعة دورية، والمواصفات المحمية لا يجوز نسخها كاملة دون ترخيص.
7. لا يوجد حتى الآن نظام تحرير ومراجعة علمية أو إدارة مدربين وتقييم عملي موثق يغطي دورة الاعتماد.

## ما تم تنفيذه

- مدخل جديد افتراضي للأكاديمية: مكتبة الدروس والمراجع، بنفس الهوية الكحلية والذهبية ودعم RTL/LTR.
- 23 درساً تأسيسياً أصلي الصياغة باللغتين؛ كل درس يتضمن متطلبات سابقة ومبدأ وتطبيقاً وحدوداً ومثالاً وسؤال فهم وتصحيحاً ومصادر للقراءة.
- بحث في العناوين والشرح باللغتين مع تسوية بعض اختلافات كتابة العربية، وتصفية وفق المجالات الثمانية.
- ترتيب بداية مقترح: السلامة ← القياس ← التأهيل ← الموجات.
- فتح المنهج المرتبط، والتنقل إلى الدرس التالي، وحفظ علامة القراءة محلياً بمفتاح مستقل عن تقدم المنهج.
- 14 رابطاً مرجعياً من جهات متخصصة؛ النوع والناشر ظاهرين مع كل رابط. بعضها أدلة تاريخية تعليمية وليست متطلبات تنظيمية حالية.
- تنبيه عام لكل تبويبات الأكاديمية عن حدود التعليم والمحاكاة والتأهيل، وتصحيح وصف مكتبة الأكواد.
- إصلاح استدعاء `setPassedModules` غير الموجود في نافذة الاختبار، واستبداله بتحديث تقدم الوحدات من مصدره الحالي.
- اختبارات بيانات وتفاعل قابلة للتشغيل دون خدمة AI أو Firebase.

## التغطية الجديدة وحدودها

| المجال | الدروس الجديدة | ما يلزم استكماله |
|---|---|---|
| الأساسيات وNDT التقليدي | القياس، الموجات، VT، PT، MT، UT، RT | وحدات منفصلة لكل طريقة، حالات عيوب متنوعة، حسابات ومعايرة وتمارين ميدانية بإشراف |
| NDT المتقدم | ET، PAUT، TOFD، LT، AE | FMC/TFM، الموجات الموجهة، MFL، التصوير الحراري، CR/DR، المركبات، إعدادات الأجهزة وتحليل بيانات فعلية مرخصة |
| اللحام | WPS/PQR وتأهيل اللحام، طاقة القوس | عمليات اللحام تفصيلياً، المتغيرات حسب الكود، الرسومات والرموز، اختبارات الإتلاف وتقييم عيوب اللحام |
| المعادن وPWHT | البنية المجهرية، PWHT والتسخين المسبق | مخططات الأطوار، CCT/TTT، سبائك Cr-Mo وP91، الصلادة وPMI، الزحف والتعب، مراجعة دورات فعلية |
| التآكل والدهانات | آليات التلف، تجهيز السطح وفحص الطلاء | برامج API 571، الحماية الكاثودية، CUI، اختبارات الالتصاق والأملاح والمسامية والإنضاج مع المواصفات |
| API | معدل التآكل والعمر المتبقي | مسارات مستقلة لـ510/570/653، حسابات الكود والرسومات والإصلاحات وفق نسخ مرخصة ونافذة الامتحان |
| سلامة الأصول | RBI/FFS، السلامة | برنامج API 580/581 وتقييمات FFS متعددة المستويات، تحليل الفشل، تدريب وصول وإنقاذ مع جهة مختصة |
| الجودة والتأهيل | QA/QC وITP والتتبع، خريطة التأهيل والأكواد | إدارة عدم المطابقة والتدقيق، ISO 9001/17020/17025، إحصاء واحتمال كشف POD وتقييم كفاءة عملي |

الدروس تأسيسية قصيرة، وليست مقررات جامعية كاملة أو بديلاً عن دورات Level I/II/III. زمن الدراسة المعروض تقدير للمطالعة والتمرين، لا ساعات حضور أو تدريب معتمدة. سؤال واحد لكل درس هو فحص فهم، لا امتحان كفاءة.

## المصادر والمنهجية

الدليل القابل للتحديث موجود في `src/data/academyKnowledge.ts`، مع روابط كل درس إلى القراءة الداعمة:

- IAEA: إرشادات التدريب TECDOC-628/Rev.2 وكتاب PT/MT TCS-11؛ تستخدم للمبادئ والمناهج فقط، لا حدود جرعات أو تشريعات حالية.
- ASNT: تعريف الطرق، التأهيل، LT وAE.
- TWI: PAUT وTOFD وقابلية اللحام والهيدروجين.
- API: صفحات 570 و580 وملفات Body of Knowledge وEffectivity ذات الصلة.
- AMPP: نطاق برنامج مفتش الدهانات.
- ISO: التعريف بكفاءة المختبرات ISO/IEC 17025.

هذه مصادر بحث وقراءة، ولا تعني أن الجهات اعتمدت المحتوى أو أنها شريكة للأكاديمية. لم تُنسخ أكواد مدفوعة أو بنوك امتحانات رسمية. الأمثلة مؤلفة للتعليم مع افتراضات وحدود ظاهرة. يجب إسناد مراجعة المحتوى التفصيلي إلى متخصصين مؤهلين قبل تسويقه كتدريب مهني.

## خطة الاستكمال بالأولوية

### 1. تحويل مخطط المنهج إلى مقررات فعلية

لكل طريقة ومستوى: اختبار تشخيصي، متطلبات سابقة، أهداف قابلة للقياس، دروس مشروحة، رسومات موثقة الترخيص، أمثلة وتمارين متنوعة، اختبار نهائي مع خريطة تغطية، سجل مراجعة علمية ونسخة وتاريخ ومراجع. ابدأ بالـVT/PT/MT/UT ثم اللحام والمعادن. لا تُنشَر الوحدات الناقصة بوصفها مكتملة.

### 2. حوكمة المحتوى والسلامة

تعيين مراجع Level III للـNDT، ومتخصصي لحام ومعادن وتآكل وAPI لكل مسار. مراجعة الأرقام الموجودة في المناهج حسب الطريقة والنظام والإصدار. إعادة تسمية أي شهادة ناتجة عن اختبار الموقع إلى «إفادة تعلم ذاتي غير معتمدة» بعد مراجعة جميع القوالب. مراجعة المحاكاة والحاسبات والإجابات بالأسئلة الحالية، خصوصاً حدود PWHT وقبول العيوب.

### 3. تعلم وتقييم عملي موثق

تسجيل مدربين وأدوار ومجموعات، خطط تدريب معتمدة عند توفر الاعتماد الحقيقي، عينات ممثلة وبيانات أجهزة فعلية، قوائم تقييم عملية يوقعها مقيم مؤهل، سجل خبرة بإشراف، وسياسة واضحة للتحقق من الهوية والتظلمات وإعادة الاختبار. لا يُستبدل ذلك بالنقر على «قرأت» أو النجاح في محاكاة.

### 4. بنية أكاديمية إنتاجية

CMS لإدارة الدروس والمصادر والمراجعات والنشر، مزامنة تقدم آمنة لكل متعلم بقواعد وصول مختبرة، نسخ احتياطي وتصدير ومحو بيانات، مراقبة توفر الروابط، ترجمات كاملة، وسائط مع نصوص بديلة وترجمات فيديو، واختبارات متصفح فعلية على الهاتف وسطح المكتب. المحتوى الأساسي يجب أن يستمر دون AI. الخدمات الذكية تحتاج استضافة Node/WebSocket وحماية مفاتيح وحدود استخدام، ولا تعمل عبر Pages وحده.

## التحقق

```bash
npm ci
npm run test:academy
npm run lint
npm run build
npm run preview -- --host 0.0.0.0
```

الاختبارات تغطي صحة معرفات الدروس والمراجع والإجابات، تغطية المجالات، البحث والتصفية، العربية وRTL، السؤال والمحاولة، الربط بالمنهج، حفظ القراءة وعزلها عن التقدم القديم، فساد بيانات التخزين، وروابط المصادر. هذه اختبارات DOM عبر jsdom وليست اختبارات عرض بصري. تعذر تنزيل متصفح Playwright بسبب حظر اتصال مضيف التنزيل، لذلك يلزم فحص بصري حقيقي قبل النشر النهائي. بيئة العمل الحالية Node 22؛ المشروع يوصي Node 24.12+ لمتطلبات Firebase.

- تقدم التعلم (سجل قراءة) منفصل عن أي ادعاء اعتماد.
