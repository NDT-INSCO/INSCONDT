# Google AI Studio / Gemini API — ما طُبِّق وما لم يُطبَّق

آخر تحديث: أكتوبر 2026.
هذا الملف يشرح كيف صار "مستشار NDT الذكي" في أكاديمية إنسكو مبنياً على
واجهات Google الحالية، وما الذي رُفض تطبيقه وسببه، وكيف يُشغَّل ويُختبر.
المرجع التنفيذي هو الكود نفسه: `src/ai/*` و`server.ts`.

---

## 1. الخلاصة في ثلاثة أسطر

- الموقع يُنشر ملفات ثابتة على GitHub Pages، والمفتاح لا يجوز أن يكون فيه.
  لذلك أُضيفت **بوابة خادم** صغيرة (`server.ts`) تحمل المفتاح وتتحدث مع Gemini.
- الطلب يمر عبر بحث حقيقي في مكتبة إنسكو (132 وثيقة) قبل النموذج، وكل إجابة
  تحمل **استشهادات** بصفحات حقيقية. بلا مطابقة ⇒ رفض صريح، لا تخمين.
- الواجهة الحالية تُسمّى **Interactions API** وهي المسار الأول؛ واجهة
  `models.generateContent*` القديمة بقيت كاحتياط فقط.

## 2. ما الجديد في منصة Google (حتى أكتوبر 2026) وموقفنا منه

| القدرة | الحالة في المشروع | لماذا |
| --- | --- | --- |
| **Interactions API** (`interactions.create`) — الواجهة الأساسية الجديدة | ✅ مطبَّقة كمسار أول | تشغيل أطول، أحداث SSE واضحة، `background`، ومسار Google نفسه |
| نماذج **Gemini 3.8 Flash** (بديلة 3.6، و2.5 كاحتياط أخير) | ✅ | أرخص وفصاحة عربية جيدة للمحتوى التقني |
| **Gemini 4 Argon** كنموذج "deep" | ⏸️ معرَّف في العقد، غير مستخدم افتراضياً | سعره $2/$10 لكل مليون توكن؛ يُستخدم لسؤال مقارنات عميقة عند الطلب فقط |
| **Abort / streaming عبر SSE** | ✅ | زر "إيقاف" حقيقي، وتحرير الاتصال عند إغلاق الصفحة |
| **Structured output** (JSON schema) | ⏸️ مرحلة لاحقة | الاستشهادات الحالية تُستخرج من المكتبة لا من النموذج، فلا حاجة لـ JSON الآن |
| **`store: false`** | ✅ | أسئلة المتدربين لا تُحفظ على خوادم Google |
| **Auth keys** (سياسة 2026: مفتاح مقيد بالخادم) | ✅ | المفتاح خادمي فقط؛ لا يوجد أي شيء من AI في حزمة المتصفح |
| **Rate limits / Budget** | ✅ | 10/دقيقة و200/يوم لكل IP + سقف 300 طلب/يوم للمفتاح ⇒ 429 مع `Retry-After` |
| **TTS** (`gemini-3.8-flash-tts`, `/v1beta/voices`) | ⏸️ مرحلة P4 | قراءة الدرس صوتياً مفيدة لكنها تكلّف ضعف النص؛ تحتاج واجهة تحكم كاملة |
| **Live API** (`gemini-3.8-live`) | ❌ مرفوضة الآن | محادثة صوتية حيّة = تكلفة مفتوحة + اختبار غير قابل للتكرار في CI |
| **Veo / توليد فيديو** | ❌ مرفوضة | `IndustrialVideoGen` ما زال هيكلاً؛ الفيديو ليس محتوى NDT موثوقاً بلا مراجعة Level III |
| **Embeddings** (`gemini-embedding-2`) | ⏸️ بديل مستقبلي | BM25 الحالي يعطي نتائج دقيقة بالعربية وبلا تكلفة؛ التضمين يحتاج فهرساً ثابتاً وفاتورة لكل بحث |
| **Managed Agents / background=True** | ❌ غير مطلوبة | لا يوجد وكيل طويل التشغيل في هذا النطاق |
| **Flex / Priority tiers** | ⏸️ عند النشر | `service_tier` يُضبط في الخادم إذا احتجنا تسعيراً أرخص لحركة غير عاجلة |

**مبدأ عملي:** لم يُطبَّق شيء لمجرد وجوده في المنصة. كل قدرة دخلت لأن لها
وظيفة في الأكاديمية، وكل ما دخل ما زال قابلاً للاختبار بلا شبكة ولا مفتاح.

## 3. المعمارية

```
المتصفح (GitHub Pages, ثابت)
  ├── src/ai/search.ts  ← بحث BM25 داخل المتصفح (يعمل بلا خادم)
  ├── src/ai/corpus.ts  ← 132 وثيقة من نفس بيانات الكتب والمقررات
  └── src/ai/client.ts  ← fetchTutorStatus / streamTutor
            │  POST /api/ai/tutor   (SSE)
            ▼
server.ts  (Express + @google/genai)
  ├── تحقق من الطلب            → 400 invalid_request
  ├── حد المعدل والسقف اليومي    → 429 rate_limited / budget_exhausted
  ├── هل يوجد مفتاح؟            → 503 not_configured (لا نص مزيّف)
  ├── استرجاع المقاطع + عتبة 4.2  → لا مطابقة = رفض صريح
  └── streamTutorText()
        ├── interactions.create({ stream: true })   ← المسار الأول
        └── models.generateContentStream(...)       ← احتياط (TUTOR_API_MODE)
            │
            ▼
        Gemini (3.8 Flash → 3.6 Flash → 2.5 Flash)
```

نقاط التصميم المهمة:

1. **لا مفتاح في المتصفح.** `src/ai/client.ts` يستدعي `gatewayBase()` التي تقرأ
   `VITE_AI_BASE_URL`، وإن كانت فارغة فالمسار نسبي `/api/ai/*`.
   على GitHub Pages لا يوجد خادم ⇒ الحالة `unreachable` وتقول الواجهة ذلك.
2. **حقيقة واحدة للأرقام.** عدد الصفحات والدروس يُشتق من `getCorpusStats()`
   (90 صفحة و35 درساً و7 مقررات = 132 وثيقة)، والرسالة التي كانت تقول
   "157 صفحة" ثابتة يدوياً صُحِّحت.
3. **العقد واحد.** `src/ai/contract.ts` يحدد النماذج والحدود والمسارات وأحداث
   SSE وأكواد الخطأ. الخادم والمتصفح والاختبارات تقرأ منه، فلا يتفرّق الاتفاق.
4. **`src/ai/transport.ts` معزول.** يستقبل عميلاً بنيوياً بسيطاً، لذا يُختبر
   بمزيف بلا شبكة، ولا يدخل في حزمة المتصفح.

## 4. آلية تنفيذ المسار الأول (Interactions API)

```ts
const stream = await ai.interactions.create(
  {
    model: 'gemini-3.8-flash',
    input: prompt,                 // المقاطع المسترجعة + السؤال
    system_instruction: system,
    generation_config: { temperature: 0.35, max_output_tokens: 1600 },
    stream: true,
    store: false,                  // لا نحفظ سؤال المتدرب
  },
  { signal }                       // إلغاء حقيقي عند إغلاق الصفحة أو المهلة
);

for await (const event of stream) {
  if (event.event_type === 'step.delta' && event.delta?.type === 'text') {
    yield event.delta.text;
  } else if (event.event_type === 'error') {
    throw new Error(event.error?.message ?? 'interaction stream reported an error');
  }
}
```

قواعد ثابتة في `streamTutorText`:

- **تسلسل النماذج** يعمل داخل النقل الواحد: نموذج غير موجود (404) ⇒ التالي.
- **لا تبديل صامت للنقل:** لو فشل الطلب بسبب الشبكة أو السلامة، يُبلَّغ الخطأ.
  الاحتياط القديم يعمل فقط إذا كانت الواجهة نفسها غير متاحة لهذا المشروع
  (`404/405/501/not implemented`)، ويُسجَّل سبب التبديل في سجل الخادم.
- **لا تكرار للنص:** إذا بدأ النموذج بالبث ثم فشل، لا يُعاد بالسؤال إلى نموذج
  آخر، وإلا قرأ المتدرب البداية مرتين.
- **الإلغاء صامت:** `AbortSignal` يوقف كل شيء دون رسالة خطأ للمستخدم.

التبديل يدوياً بمتغير واحد:

```bash
TUTOR_API_MODE=interactions   # الواجهة الحديثة فقط (يفشل بوضوح)
TUTOR_API_MODE=auto           # الافتراضي: حديث ثم قديم عند الحاجة
TUTOR_API_MODE=legacy         # القديم فقط (مفتاح/project قديم)
```

## 5. الاسترجاع والاستشهادات

`retrieveForTutor(question, { limit: 5 })` يبحث في:

- 90 صفحة كتاب + 7 نظرات عامة للمقررات + 35 درساً = 132 وثيقة.
- تطبيع عربي (همزات، تشكيل، أرقام) + جذوع + مرادفات ثنائية اللغة
  (`src/ai/synonyms.ts`) + BM25 مع وزن عنوان ×2.4.
- عتبة `minScore = 4.2`. أقل من ذلك ⇒ `confident: false`.

عند `confident: false` يحدث الآتي:

1. يُرسَل حدث `meta` بعدد استشهادات = 0.
2. تُكتب رسالة صريحة (بالعدد الحقيقي: 90 صفحة و35 درساً) تقول إن المكتبة لم
   تجد مطابقة وتقترح صياغة أخرى أو البحث اليدوي.
3. **لا يُستدعى النموذج أصلاً**، فلا يمكنه اختراع مصدر.

كل معرف استشهاد هو معرف حقيقي (`book-vt#p1`، `nde-ut#ut-calibration`)، والواجهة
تحوّله إلى قفزة مباشرة: الكتاب إلى صفحته داخل `EdbFlipbook`، والدرس إلى مقرره.
هذا ما يجعل `#edb` و`initialPage` جزءاً من العقد مع البحث.

## 6. الحدود والتكلفة

| الحد | القيمة | مكانها |
| --- | --- | --- |
| طول الرسالة | 4000 حرف | `TUTOR_LIMITS.messageChars` |
| عدد الرسائل في المحادثة | 20 | `TUTOR_LIMITS.messages` |
| مقاطع السياق | 5 (حد 9000 حرف) | `TUTOR_LIMITS.passages/contextChars` |
| توكنات الإجابة | 1600 | `TUTOR_LIMITS.outputTokens` |
| طلبات/دقيقة/IP | 10 | `TUTOR_RATE_PER_MINUTE` |
| طلبات/يوم/IP | 200 | `TUTOR_RATE_PER_DAY` |
| سقف يومي للمفتاح | 300 | `TUTOR_DAILY_LIMIT` |
| مهلة الطلب | 45 ثانية | `TUTOR_TIMEOUT_MS` |

التجاوز ⇒ `429` مع `Retry-After`. السقف اليومي ⇒ `budget_exhausted`.
التقدير الحالي: 1.5k توكن إدخال + 600 خروج ≈ **$0.0034 لكل سؤال** على
3.8 Flash، أي نحو 300 سؤال/شهر ≈ دولار واحد.

## 7. متغيرات البيئة

انظر `.env.example` (كلها اختيارية إلا المفتاح):

```
GEMINI_API_KEY=            # خادمي فقط
VITE_AI_BASE_URL=          # عنوان البوابة إن كانت على نطاق آخر
TUTOR_API_MODE=auto
TUTOR_MODEL=               # تثبيت نموذج معيّن
TUTOR_RATE_PER_MINUTE=10
TUTOR_RATE_PER_DAY=200
TUTOR_DAILY_LIMIT=300
TUTOR_TIMEOUT_MS=45000
PORT=3000
```

`VITE_AI_BASE_URL` تُحرَق وقت البناء، فهي تُضبط قبل `npm run build` عندما تكون
البوابة على Cloud Run، وتُترك فارغة عندما تكون البوابة نفس نطاق الصفحة.

## 8. التشغيل والنشر

**محلياً:**

```bash
cp .env.example .env      # ضع GEMINI_API_KEY
npm install
npm run dev               # tsx server.ts → http://localhost:3000
```

**على Cloud Run / أي استضافة Node:**

```bash
GEMINI_API_KEY=... TUTOR_API_MODE=auto PORT=8080 npx tsx server.ts
```

ثم اضبط في بناء الصفحات: `VITE_AI_BASE_URL=https://<service-url>`، وأعد البناء.

**على GitHub Pages (بلا خادم):** يبقى الموقع صالحاً بالكامل — الكتب والمقررات
والبحث والامتحانات تعمل؛ تبويب المستشار يقول صراحةً إن البوابة غير موصولة،
ولا يطبع إجابة جاهزة.

> مهم: لا تضع `GEMINI_API_KEY` في أي ملف يذهب إلى `docs/` أو `public/`.
> سياسة مفاتيح AI Studio (2026) ترفض المفاتيح المكشوفة، والحزمة الثابتة عامة.

## 11. ما لا يفعله هذا النظام

- لا يصدر شهادات ولا يمنح اعتماداً. الشهادة الموجود في `certificates` هي
  **بيان دراسة ذاتية غير معتمدة**، مستقلة تماماً عن أي استعمال لـ Gemini.
- لا يجيب من خارج مكتبة إنسكو. إن لم يجد مصدراً في المكتبة يسأل عن صياغة أخرى.
- لا يخزّن أسئلة المتدربين (`store: false`).
- لا يعمل بلا مفتاح، وهذا مقصود: صفحة ثابتة بلا بوابة يجب أن تقول ذلك.
